# 云台 PID 实机调试

以下为当前源码参数，针对本机当前负载和 MPU6500 陀螺仪 92 Hz 滤波配置。Yaw 已按用户要求停止调参；通用目标差分速度前馈已编译，尚未烧录和实机复测。负载、安装刚度或滤波配置改变后需重新验证。

| 轴 | 角度环 Kp / Ki / Kd | 速度环 Kp / Ki / Kd | 角度环积分限幅 | 速度环积分限幅 |
| --- | --- | --- | --- | --- |
| Yaw | 40 / 0 / 0 | 50 / 200 / 0 | 100 | 3000 |
| Pitch | 100 / 250 / 0.5 | 80 / 150 / 0 | 100 | 6000 |

Yaw 角度环输出限幅为 250，速度环为 12000，角度死区为 0.1°；Pitch 角度环输出限幅为 500，速度环为 20000，角度死区为 0°。Yaw 速度前馈由独立函数计算 `0.90 × Δyaw目标 / 实际Δt`，限幅 ±250°/s，经 `speed_feedforward_ptr` 接入速度环，不依赖正弦解析导数。禁用及首次使能时重置差分历史。电流前馈未启用。

## 正弦验收

固件和 `build/basic_framework_ATYPE.elf` 必须匹配，启动项目 OpenOCD（`openocd_dap.cfg`），TCL 端口为 50001。脚本从 ELF 获取全局变量地址；电机结构体偏移对应当前仓库布局。

机器人须留出运动空间；摇杆、拨轮回中，右开关上档，底盘处于无跟随模式。按顺序单轴测试：

```powershell
python tests/gimbal_pid/run_sine.py --axis yaw --name yaw_final_acceptance --amplitude 60
python tests/gimbal_pid/run_sine.py --axis pitch --name pitch_final_acceptance --amplitude 25
```

默认频率 0.25 Hz、时长 52 s；首尾各一周期线性调整幅值。分析 8～48 s，共 10 个完整周期。目标为 RMS 误差 ≤0.5°、峰值误差 ≤1°，无输出饱和，并需现场确认运动平顺、无持续抖动或异响。

这里的角度误差使用 IMU 姿态反馈计算，不代表外部测量的绝对航向精度。

以下为早期固件的历史测试记录，不代表当前 Kp=40 与通用差分前馈版本已通过验收。用户曾确认该轮 Pitch 连续运动平顺，无明显抖动或异响。

| 轴 | RMS误差 | 峰值误差 | 输出峰值占限幅 |
| --- | --- | --- | --- |
| Yaw | 0.396° | 0.901° | 20.8% |
| Pitch | 0.295° | 0.942° | 33.8% |

曲线和完整数据位于 `build/gimbal_pid/acceptance.md`、`acceptance.png` 与两个 `*_final_acceptance` 文件。稳定后30秒Yaw编码器变化约0.44°，仍有残余漂移；启动瞬态另存为 `imu_post_restart_transient`，未混入此统计。

目标在板上连续生成。`gimbal_sine_test` 上电默认关闭：`axes` 为 0/1/2/3，分别表示关闭/Yaw/Pitch/双轴。设置幅值、频率、时长后最后写入 axes。开始时捕获当前姿态作为中心，另一轴保持其起始角度；结束后保留最后一次目标。急停优先。Pitch 软件限位为 −40°～+30°，±25°测试要求起始实际俯仰在 −15°～+5°以内。源码正弦默认频率为 0.35 Hz，脚本默认仍为 0.25 Hz，可用 --frequency 指定。

板上缓冲为 1280 条、每条 9 个 float（约 45 KiB），默认间隔至少 50 ms。CSV 包含实际采样时间；不要将名义周期视为精确采样周期。短时运动诊断可提高采样频率：

```powershell
python tests/gimbal_pid/run_sine.py --axis pitch --name pitch_motion_trace --amplitude 25 --duration 20 --record-period 20
```

`build/gimbal_pid/` 中的 `.csv` 为板上目标、角度、误差、输出；`_live.csv` 为较慢的 SWD 现场快照，包含速度环与 IMU 数据；`.json` 为参数和误差统计。脚本遇到遥控输入改变、跟踪误差过大或输出接近限幅会结束测试。测试参数仅写入 RAM；固化参数须修改 `application/gimbal/gimbal.c` 并编译下载。

## 分角度诊断

```powershell
python tests/gimbal_pid/run_hold.py --name pitch_hold_diagnostic --trace
```

依次检查 −25°、−15°、0°、15°、25°、0°。`arrival_peak_error_deg` 保留前两秒的到位误差；`settled_passed` 只表示两秒后的静止数据达标，不能代表移动过程无抖动。移动目标由 SWD 分段写入，存在阶梯，会激起振荡；运动平顺性应以板上连续正弦测试为准。

`--trace` 在接近目标时启动至少 5 ms 间隔的板上记录，实际速率受 RobotTask 调度影响。轨迹文件的时间是上电后的秒数。缓冲满后停止记录，测试结束恢复 50 ms 周期；`gimbal_trace_active=0` 可停止额外记录。

## IMU 启动

恒温目标为 50℃。初始化先预热，温度进入 ±0.5℃并持续 2 s 后进行静止校准；预热最多等待 60 s。校准检查重力均值、陀螺仪波动和偏置范围，每 15 s 未成功会输出诊断并重试，校准成功后才完成电机初始化。保持机器人静止；启动时间可能延长。

已去掉静止加速度峰峰值导致的误拒绝，保留重力均值和陀螺仪静止检查；校准失败不再使用不匹配的固定旧偏置启动。温度原始值按有符号数解析，加热输出限制在 0～100%。

云台启动时，电机先保持停止；首次 IMU 姿态数据有效且 Pitch 在 ±30°内后，以当前 Yaw/Pitch 姿态初始化目标并使能。Pitch 超出软件限位时云台保持停止，需先在断电状态解除阻挡并将机械位置放回限位范围，再上电。

这套姿态融合没有绝对航向观测，Yaw 仍可能存在长期积分漂移。软件复位验证不能替代断电后的冷启动验证。
